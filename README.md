# Moscow-Tourist-Guide
Туристический гид по Москве - гибкое приложение для планирования прогулок и посещения различных достопримечательностей города.

## Использование приложения
Установить приложение можно по ссылке: https://drive.google.com/file/d/1mIdP6WqTLwsu1vARL0AqvOp1N4QtNZMT/view?usp=sharing 

### Авторизация
Использование начинается с регистрации или авторизации пользователя

### Мои маршрута
Следом открывается экран со всеми добавленными маршрутами. У маршрута отображается процент прохождения, а также статус: не начат, в процессе, завершен, отменен.

### Создание маршрута
Маршрут можно "собрать" двумя способами: при помощи интерактивной карты с отмеченными точками интереса или же найдя нужные места в поисоквой строке.

### Оптимизация маршрута
Приложение оптимизирует маршрут по времени обхода достопримечательностей. Это помогает сократить время в дороге и потратить больше времени на просмотр мест и культурное просвещение.

### Прохождение маршрута
Пользователь может выбрать составленный маршрут и начать его обход, используя приложение как интерактивный гид, дающий информацию о достопримечательностях. Исследованные точки помечаются пройденными, прогресс отображается в прогресс баре.

### Достижения
Приложение предлагает систему достижений, которые пользователь может просмотреть на специальном экране. Например, достижения "Обойти 10 достопримечательностей" или "Посетить все достопримечательности XVIII века".
