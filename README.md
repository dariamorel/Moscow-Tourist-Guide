# Moscow-Tourist-Guide
Туристический гид по Москве - гибкое приложение для планирования прогулок и посещения различных достопримечательностей города.

## Использование приложения

### Авторизация
Использование начинается с регистрации или авторизации пользователя

### Создание маршрута
Следом, открывается экран создания маршрута. Маршрут можно "собрать" двумя способами: при помощи интерактивной карты с отмеченными точками интереса или же найдя нужные места в списке

### Редактирование маршрута
После выбора точек интереса есть возможность отредактировать порядок их обхода. Приложение может подсказать оптимальный по времени прохождения порядок

### Прохождение маршрута
Пользователь может выбрать составленный маршрут и начать его обход, используя приложение как интерактивный гид, дающий информацию о достопримечательностях

### Маршруты
Пользователь может открыть экран со своими пройденными, незаконченными или закрытыми маршрутами с возможностью просмотреть его или закончить

### Достижения
Приложение предлагает систему достижений, которые пользователь может просмотреть на специальном экране. Например, достижения "Обойти 10 достопримечательностей" или "Посетить все достопримечательности XVIII века"
